# BalloonHunter Demo Video Instructions

**Purpose:** Apple App Store Review requires a demo video showing the app working with MySondyGo hardware.

**Review Request ID:** 20b1826d-41da-4e95-8fc6-db265b9d7a6c

---

## Equipment Needed

- [ ] iPhone or iPad running BalloonHunter v1.0
- [ ] MySondyGo BLE receiver device
- [ ] Camera/phone to record the demo
- [ ] Good lighting
- [ ] (Optional) Active weather balloon for live data

---

## Video Structure

### Scene 1: Hardware Introduction (5-10 seconds)
- Show MySondyGo device clearly on camera
- Show iPhone/iPad with BalloonHunter app icon visible
- Brief view of both devices together

### Scene 2: App Launch & BLE Pairing (15-20 seconds)
- Open BalloonHunter app
- Show the app scanning for BLE devices
- MySondyGo device should be powered on
- Capture the connection state changing (connecting → connected)
- Show "readyForCommands" or "dataReady" state in UI

### Scene 3: Live Telemetry Display (20-30 seconds)
- Show telemetry data appearing on screen:
  - Sonde name (e.g., "V4210129")
  - Latitude/Longitude coordinates
  - Altitude (meters)
  - Vertical speed
  - Horizontal speed
  - Signal strength (dBm)
- Show data updating in real-time

### Scene 4: Map & Tracking Features (20-30 seconds)
- Show the map view (70% of screen)
- Display balloon position marker
- Show flight track (if available)
- Show prediction overlay:
  - Predicted path
  - Landing zone
  - Burst point (if ascending)
- Demonstrate map interactions (zoom, pan)

### Scene 5: Navigation & Settings (15-20 seconds)
- Show transport mode picker (car/bike)
- Demonstrate "Navigate" button to Apple Maps
- Open Settings screen
- Show Station ID configuration
- Show any BLE device settings

---

## Filming Tips

1. **Frame both devices** - Keep MySondyGo and iPhone visible together when possible
2. **Good lighting** - Ensure screen is readable, avoid glare
3. **Steady camera** - Use tripod or stable surface
4. **Screen recording** - Consider combining external video with iOS screen recording
5. **Clean UI** - Hide any debug/test data
6. **Landscape orientation** - Better for showing the map-centric interface

---

## Audio/Narration Options

**Option A: Silent with text overlays**
- Add text captions explaining each step
- Easier to produce, no language barrier

**Option B: Voice narration**
- Explain what's happening in each scene
- More engaging but requires clear audio
